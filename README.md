# NibleGibleGames

NibleGibleGames is a small collection of weird, replayable browser games. Each game is treated as a separate **cartridge**, with new cartridges added over time.

No login, database, or leaderboard — just simple games you can pick up and play.

---

## **Cartridges**

### IRL-DINO

A webcam-controlled dinosaur game where you duck and lean to avoid obstacles using real-time pose tracking.

### ODD or EVEN

A text-based hand-cricket game where you call odd or even, win the toss, and play through a short 3-wicket match.

### IRL-HOOPS

A physics-based basketball game controlled using your tracked hand. Throw the ball and try to score within the shot clock.

### More Coming Soon

Additional cartridges are currently in development.
